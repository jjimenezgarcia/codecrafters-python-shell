# codecrafters-python-shell

[![progress-banner](https://backend.codecrafters.io/progress/shell/493f6b74-3791-4d60-a898-dd2a1e6250f5)](https://app.codecrafters.io/users/jjimenezgarcia?r=2qF)

My solution to the ["Build Your Own Shell"](https://app.codecrafters.io/courses/shell/overview) challenge on CodeCrafters: a POSIX-style shell in Python with builtins (`cd`, `pwd`, `echo`...) and support for running external programs.

No AI used (except from coding questions without context), so don't treat this as an example!

## Running it

Requires [uv](https://docs.astral.sh/uv/).

```sh
./your_program.sh
```
